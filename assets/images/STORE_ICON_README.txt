Arquivo para substituir:
- assets/images/store-icon-1024x1024.png

Especificação recomendada (Play Store e App Store):
- Tamanho: 1024x1024 px
- Formato: PNG
- Fundo: sem transparência (recomendado para lojas)
- Sem texto pequeno

Como usar no projeto (Expo):
- Se quiser usar este arquivo como ícone principal, altere no app.json:
  expo.icon = ./assets/images/store-icon-1024x1024.png

Observação:
- Android adaptive icon já usa foreground/background próprios em app.json.
- Este arquivo é para o ícone de loja e também pode ser reaproveitado como icon principal.
